# ThinkNode Series

The ThinkNode Series, designed by Elecrow and powered by Meshtastic, offers a set of compact and dependable devices built for off-grid communication and mesh networking. Designed for portability, long battery life, and reliable wireless performance, they are well-suited for outdoor and remote use.

**ThinkNode M1**

## ThinkNode M1

The ThinkNode M1 is a compact Meshtastic device featuring an nRF52840 MCU, SX1262 LoRa transceiver, built-in GPS, and a 1.54" e-ink display. It includes a 1200 mAh rechargeable battery, and comes pre-installed with Meshtastic with an optional durable enclosure.

### Specifications

- **MCU:**
  - nRF52840
    - Bluetooth 5.0
- **LoRa Transceiver:**
  - Semtech SX1262
- **Frequency Options:**
  - US (902.0Mhz to 928.0Mhz)
  - EU_868
- **Navigation Module:**
  - L76K
- **Antenna:**
  - RP-SMA
- **Connectors:**
  - USB-C

### Features

- Meshtastic pre-installed.
- 1.54" e-ink display.
- 1200 mAh rechargeable battery.
- Integrated buzzer.
- Rotary encoder for backlight control.

**ThinkNode M3**

## ThinkNode M3

The ThinkNode M3 is a compact, card-style Meshtastic tracker featuring an nRF52840 MCU, Semtech LR1110 LoRa transceiver, and built-in GNSS module. It includes a 770 mAh rechargeable battery with magnetic charging, integrated environmental sensors, and an IP66-rated enclosure for indoor and outdoor positioning.

### Specifications

- **MCU**
  - nRF52840 (Bluetooth 5 LE)
- **LoRa Transceiver**
  - Semtech LR1110
- **Frequency options**
  - 915 MHz
  - 868 MHz
- **GNSS Module**
  - ATGM336H-5NR32
- **Battery Capacity**
  - Rechargeable lithium battery, 770 mAh
- **Charging**
  - USB magnetic charging cable

### Features

- Compact, pocket-sized design.
- Integrated Temperature, Humidity, and Accelerometer sensors.
- Four pogo pins for USB, DFU, serial logging, and charging.
- IP66 rated, waterproof and durable for various environments.

**ThinkNode M4**

## ThinkNode M4

The ThinkNode M4 is a power-bank-style Meshtastic node built around an nRF52840 MCU and a Semtech LR1110 transceiver. It pairs a 7000 mAh 18650 battery (with USB-C and wireless charging output) with multi-constellation GNSS tracking, so it doubles as a portable power bank and a mesh node.

### Specifications

- **MCU:**
  - nRF52840
    - Bluetooth 5.4 LE
- **LoRa Transceiver:**
  - Semtech LR1110
- **Frequency Options:**
  - US (902.0Mhz to 928.0Mhz)
  - EU_868
- **Navigation Module:**
  - Multi-constellation GNSS (GPS, BeiDou, GLONASS, QZSS)
- **Battery Capacity:**
  - 18650 Li-ion, 7000 mAh (25.2 Wh)
- **Connectors:**
  - USB-C (power in/out)
  - Qi wireless charging output

### Features

- Meshtastic pre-installed.
- Power-bank form factor with USB-C PD and wireless (Qi) charging output.
- Built-in GNSS tracker with track recording.
- Built-in ceramic GNSS antenna.

**ThinkNode M9**

## ThinkNode M9

The ThinkNode M9 is a handheld Meshtastic terminal with a 37-key QWERTY keyboard and a 2.4-inch color LCD, built around an ESP32-S3 MCU and a Semtech LR1110 transceiver. Multi-constellation GNSS and a magnetic compass support trajectory recording and location sharing.

### Specifications

- **MCU:**
  - ESP32-S3R8 (Xtensa LX7 dual-core, up to 240 MHz)
    - 2.4GHz Wi-Fi b/g/n
    - Bluetooth 5 LE
    - 8 MB PSRAM
- **LoRa Transceiver:**
  - Semtech LR1110
- **Frequency Options:**
  - US (902.0Mhz to 928.0Mhz)
  - EU_868
- **Navigation Module:**
  - Multi-constellation GNSS (GPS, BeiDou, Galileo, GLONASS)
- **Display:**
  - 2.4" TFT LCD, 240 x 320
- **Battery Capacity:**
  - 2300 mAh
- **Storage:**
  - 16 GB built-in memory card
- **Connectors:**
  - USB-C

### Features

- 37-key QWERTY keyboard.
- Magnetic compass.
- Trajectory recording and location sharing.
- Buzzer for alerts.
- Built-in GNSS, Wi-Fi/Bluetooth, and LoRa antennas.
- Supports the Meshtastic UI.
