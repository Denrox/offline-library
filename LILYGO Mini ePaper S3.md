# LILYGO® Mini ePaper S3

The Mini ePaper S3 is a compact ESP32-S3 node with a 1.02-inch e-ink display, built around an SX1262 LoRa transceiver. It takes an 18350 cell, which is not included.

## Specifications

- **MCU**
  - ESP32-S3FN4R2 (dual-core LX7)
    - 2.4GHz Wi-Fi, Bluetooth 5 LE
    - 4 MB flash, 2 MB PSRAM
- **LoRa Transceiver**
  - Semtech SX1262 (TCXO)
- **Frequency options**
  - 433 MHz
  - 868 MHz
  - 915 MHz
- **Display**
  - 1.02" e-ink, 128 x 80 (GDGDEWG102T4)
- **Battery**
  - 18350 Li-ion, not supplied
- **Connectors**
  - microSD card slot

## Features

- Real-time clock.
- Supports InkHUD.
- No GNSS receiver.
