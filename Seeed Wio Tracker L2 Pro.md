# Seeed Wio Tracker L2 Pro

The Wio Tracker L2 Pro is a standalone Meshtastic node with a 3.2-inch touchscreen, built on the ESP32-S3 and a Semtech SX1262. GNSS, Wi-Fi, Bluetooth, and an SD card for offline maps let it send messages and show positions without a phone.

## Specifications

- **MCU**
  - ESP32-S3 (Seeed Wio-S3 module)
    - 16 MB flash, 8 MB PSRAM
    - Wi-Fi 2.4 GHz b/g/n
    - Bluetooth 5.0 LE
- **LoRa Transceiver**
  - Semtech SX1262
- **Frequency Options**
  - 863–928 MHz
- **Navigation Module**
  - L76K GNSS (GPS, BeiDou, GLONASS, QZSS)
- **Display**
  - 3.2-inch 320 × 240 touchscreen
- **Connectors**
  - USB-C
  - Grove
  - SD card slot

## Features

- The release firmware runs Meshtastic UI on the touchscreen, and BaseUI is available from the settings menu.
- Offline maps load from the SD card.
- The Grove connector takes I²C sensors such as the BME280 and SHT31.
- An audio codec and amplifier play notification tones.
