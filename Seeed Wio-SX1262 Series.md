# Seeed Wio-SX1262 Series

**XIAO nRF52840**

## XIAO nRF52840 & Wio SX1262 Kit

> **[Note]:**
>
>
> The Wio-SX1262 module shipped with this kit does not have the same pin configuration as the one shipped with the XIAO ESP32-S3 kit. If you want to use a Wio-SX1262 module from a different Seeed kit with a XIAO nRF52840, you may need to flash custom firmware with the correct pin definitions.
>

A thumb-sized LoRa dev kit based on the nRF52840 MCU, supporting BLE, and LoRa. It includes a built-in power management chip and can be extended via I²C, UART, and other GPIO interfaces, with compatibility for Arduino development.

### Specifications

- **MCU**
  - XIAO nRF52840 (Bluetooth)
- **LoRa Transceiver**
  - Semtech SX1262
- **Frequency options**
  - 862-930 MHz
- **Connectors**
  - USB-C
  - Antenna
    - U.FL/IPEX antenna connector for LoRa

### Features

- **Thumb-sized Compact Design**: 21 x 18mm, adopting the classic form factor of XIAO.
- **L76K GNSS Module available**: A compatible Seeed L76K GNSS Module is available with the same form factor as the XIAO nRF52840 & Wio-SX1262 Kit.

**XIAO ESP32-S3**

## XIAO ESP32-S3 & Wio SX1262 Kit

> **[Note]:**
>
>
> The Wio-SX1262 module shipped with this kit does not have the same pin configuration as the one shipped with the XIAO nRF52840 kit. If you want to use a Wio-SX1262 module from a different Seeed kit with a XIAO ESP32-S3, you may need to flash custom firmware with the correct pin definitions.
>

A thumb-sized LoRa dev kit pairing the XIAO ESP32-S3 with the Wio-SX1262 module. It adds 2.4 GHz Wi-Fi and more memory than the nRF52840 kit, and can be extended via I²C, UART, and other GPIO interfaces, with compatibility for Arduino development.

### Specifications

- **MCU**
  - XIAO ESP32-S3 (Wi-Fi 2.4GHz & Bluetooth 5 LE)
    - 8 MB Flash
    - 8 MB PSRAM
- **LoRa Transceiver**
  - Semtech SX1262
- **Frequency options**
  - 862-930 MHz
- **Connectors**
  - USB-C
  - Antenna
    - U.FL/IPEX antenna connector for LoRa (2 dBi external antenna included)

### Features

- **Thumb-sized Compact Design**: 21 x 18mm, adopting the classic form factor of XIAO.
- **L76K GNSS Module available**: A compatible Seeed L76K GNSS Module is available with the same form factor as the XIAO ESP32-S3 & Wio-SX1262 Kit.
- Pre-flashed with Meshtastic firmware; a version with a 3D-printed enclosure is also available.
