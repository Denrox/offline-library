# LilyGo T-LoRa C6

The T-LoRa C6 is a compact, low-cost LoRa device built on the ESP32-C6 and an SX1262 transceiver, with an internal PCB antenna.

## Specifications

- **MCU**
  - ESP32-C6 (Wi-Fi & Bluetooth 5 LE)
- **LoRa Transceiver**
  - Semtech SX1262
- **Frequency options**
  - 868 MHz
  - 915 MHz
- **Connectors**
  - USB-C
  - Internal PCB antenna

## Features

- User button and reset switch.
- 3D-printed lid.
- No GNSS receiver.
