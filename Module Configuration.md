# Module Configuration

Modules are included in the firmware and allow users to extend the functionality of their mesh or device.

|                                    Name                                    |                                                                                                             Description                                                                                                             |
| :------------------------------------------------------------------------: | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------: |
|       [Ambient Lighting](Ambient%20Lighting%20Module%20Usage.md)     |                                                                                              Adjust the brightness of NCP5623 I2C RGB LEDs                                                                                          |
|                 [Audio](Audio%20Module%20Configuration.md)                 |                                                                                      Enable Support for Codec2 Voice Comms on certain devices.                                                                                      |
|        [Canned Message](Canned%20Message%20Module%20Configuration.md)        |                                                   Set a number of predefined messages to send out directly from the device with the use of an input device like a rotary encoder.                                                   |
|      [Detection Sensor](Detection%20Sensor%20Module%20Usage.md)      |                                                                     Configure a GPIO pin to be monitored for specified high/low status and send text alerts.                                                                        |
| [External Notification](External%20Notification%20Module%20Configuration.md) |                                                                Incoming messages are able to alert you using circuits you attach to the device (LEDs, Buzzers, etc).                                                                |
|                  [MQTT](MQTT%20Module%20Configuration.md)                  |                                              Forward packets along to an MQTT server. This allows users on the local mesh to communicate with users on another mesh over the internet.                                              |
|          [Neighbor Info](Neighbor%20Info%20Module%20Usage.md)        |                                                                                           Send info on 0-hop neighbors to the mesh.                                                                                                 |
|            [Paxcounter](Paxcounter%20Module%20Usage.md)            |                                                                                     Count the number of BLE and Wifi devices passing by a node.                                                                                     |
|            [Range Test](Range%20Test%20Module%20Configuration.md)            | Send messages with GPS location at an interval to test the distance your devices can communicate. Requires (at least) one device set up as a sender and one as a receiver. The receiver(s) will log all incoming messages to a CSV. |
|       [Remote Hardware](Remote%20Hardware%20Module%20Usage.md)       |                                                                                        Set and read a GPIO status remotely over the mesh.                                                                                           |
|            [Serial Module](Serial%20Module%20Configuration.md)             |                                                                                Send messages across the mesh by sending strings over a serial port.                                                                                 |
|  [Store & Forward](Store%20%26%20Forward%20Module%20Settings.md)   |                                                                         Stores messages on a device for delivery after disconnected clients rejoin the mesh.                                                                        |
|             [Telemetry](Telemetry%20Module%20Configuration.md)             |                                                                        Attach sensors to the device and transmit readings on a regular interval to the mesh.                                                                        |
|            [Traceroute](Traceroute%20Module%20Usage.md)            |                                                                                Track which nodes are used to hop a message to a certain destination.                                                                                |
