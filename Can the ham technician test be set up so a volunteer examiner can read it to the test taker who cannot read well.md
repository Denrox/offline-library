# Can the ham technician test be set up so a volunteer examiner can read it to the test taker who cannot read well?

*Tags: license · score 8*

## Question

My relative has wanted his ham license for many many years. However, he cannot read well.

Can the test be set up so a volunteer examiner can read it to him?

## Answer (score 11, by David Hoelzer)

The arrangements are specifically for the blind, but this seems like a perfectly reasonable accommodation.

I would strongly recommend contacting the local ham club (who typically have the Volunteer Examiners who will oversee the exam) and ask them if they can accommodate him. I can imagine there is fear and embarrassment, but my experience is that ham clubs are very accepting with very little judgement.
