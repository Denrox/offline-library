# How did telegraph operators ensure they received the intended message? Was some sort of checksum used?

*Tags: history, morse-code · score 3*

## Question

Assuming the operators were using Morse code (un-encrypted or otherwise) how could the receiver determine they got the correct message?

## Answer (score 3, by Gidge)

Good stuff! Someone was scheduled to sit at the station and await messages. It was a two way communication so the person on the receiving end could acknowledge and await the message. Each "send" started with a code so the receiver could listen for their stations ID. (town and state name) Much like computers with "handshakes" to ACK (acknowledge). They would basically say in their lingo, I am here, go ahead. There were also machines that had tape in them that would print out the dots and dashes from the code much like a mass broadcast. You can see samples of both ways in a lot of old black and white movies. Morse code becomes a second language once you use it enough. So just listening they could here their station being hailed. Many stations used the same lines. (no privacy!) Important messages that were sent were requested to be verified.
